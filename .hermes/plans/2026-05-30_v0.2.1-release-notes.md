## v0.2.1

### Features
- **Gmail OAuth2** — sign in with Google from the account manager. Browser-based auth, no app passwords needed. Refresh tokens stored in system keychain.
- **Desktop notifications** — `notify-send` fires when auto-sync finds new mail.
- **Collapse state persists** — sidebar folders no longer reset on every restart.

### Fixes
- **Auto-sync timers** (`tea.Every` is one-shot) — properly self-reschedules each tick so auto-sync keeps working.
- **Update system** — renamed assets `tide-*` → `tidemail-*` to match the repo rename. Dismiss override from Settings. Manual install command no longer hidden by dismiss flag.
- **OAuth2 UX** — Escape cancels browser sign-in wait. Focus auto-advances after sign-in. `prompt=consent` prevents "already has access" dead-end page.
- **OAuth2 config stability** — `ClientID`/`ClientSecret` no longer leak into TOML (`toml:"-"`). Env var fallback (`TIDEMAIL_GOOGLE_CLIENT_ID`/`SECRET`) for redundancy.

### Upgrade notes
- v0.1.8 users who dismissed v0.2.0: clear `dismissed_version` from your config or set env vars `TIDEMAIL_GOOGLE_CLIENT_ID` + `TIDEMAIL_GOOGLE_CLIENT_SECRET`.
- OAuth2 requires `[oauth]` section in `~/.config/tidemail/config.toml`:
  ```toml
  [oauth]
  google_client_id = "..."
  google_client_secret = "..."
  ```
