## v0.2.0

### Features

- **Gmail OAuth2** — sign in with Google from the account manager (toggle Auth to OAuth2, press Enter on [Sign in with Google]). Your browser opens, you approve, and the token is stored in the system keychain. No app passwords needed. On restart, the refresh token is restored automatically.

- **Desktop notifications** — when auto-sync finds new mail, a desktop notification fires via `notify-send` (title: account name, body: "Inbox — N new"). Only fires on background auto-sync, not manual `f`/`F` refreshes.

- **Collapse state persistence** — the sidebar's System/Labels section collapse state now survives restarts. Was stubbed out with a TODO. It now uses the existing `settings` table in the local database.

### Fixes

- **Auto-sync timers** — `tea.Every` in Bubble Tea v1 is one-shot (fires once, then stops). The old `startSyncTimersCmd()` assumed it was repeating, so auto-sync only fired once per session. Rewritten to a self-rescheduling pattern: each tick fires `AutoSyncMsg`, which syncs and then calls `scheduleNextSync` to re-register. No more timer accumulation, no more "Too many simultaneous connections" errors.

- **OAuth2 UX** — press Escape to cancel the browser sign-in wait (was stuck for 2-minute timeout). After signing in, focus jumps to the From field so accidental Enter doesn't re-trigger the flow. `prompt=consent` on the auth URL prevents the "already has access" dead-end page.

- **Fetch timing** — auto-sync and manual sync now log connect/fetch/total timing to `fetch.log` next to `config.toml`, tab-delimited. Also added an in-memory log buffer so auto-sync results appear in Settings → Advanced → View Logs without spamming the status bar.

### Known issues

- OAuth2 is currently implemented for Gmail only. Other providers fall back to password/app-password auth.
- The Google OAuth client ID and secret are not bundled in the binary (omitted from the public repo). Add them to your `~/.config/tidemail/config.toml`:
  ```toml
  [oauth]
  google_client_id = "..."
  google_client_secret = "..."
  ```
