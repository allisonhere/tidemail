## v0.2.2

### Features
- **Optimistic delete** — messages vanish instantly when you press `d`. IMAP delete runs in background. On failure, the mailbox reloads to restore missing messages.

### Fixes
- **OAuth2 config stability** — `ClientID`/`ClientSecret` no longer leak into TOML (`toml:"-"` tags). Env var fallback (`TIDEMAIL_GOOGLE_CLIENT_ID`/`SECRET`). Duplicate `[oauth]` sections no longer wipe credentials.
- **Update system** — asset names match the repo rename (`tidemail-*`). Settings check overrides dismiss flag. Manual install command reappears after failed auto-install.
- **Optimistic delete bugs** — fixed slice mutation during multi-select (range loop over filteredMessages while applyFilter rebuilt it). Commands now collected before any memory removal.

### Upgrade notes
- v0.1.8 users: the `tidemail-*` asset name fix only applies from this version forward. If stuck on v0.1.8 with a dismissed update, install v0.2.2 via curl or `go run .`.
- OAuth2 requires `[oauth]` in `~/.config/tidemail/config.toml` or `TIDEMAIL_GOOGLE_CLIENT_ID`/`SECRET` env vars.
