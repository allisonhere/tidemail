# TideMail Desktop Design System

TideMail is a keyboard-first, multi-account desktop email client. Its Native
layout should feel like a compact Linux/macOS productivity application rather
than a responsive website, while retaining the dark nautical Tide identity.

Use only the existing system sans-serif stack, the existing navy/charcoal
palette, `#58a6ff` accent, `#ff7b72` danger, and Lucide icons. Do not introduce
gradients beyond the existing small brand mark, decorative imagery, glass blur,
floating cards, marketing copy, large pills, or oversized rounded controls.

The system titlebar remains native. Inside it, use a restrained 42–44px toolbar,
three contiguous panes separated by 1px dividers and draggable splitters, compact
48–56px message rows, square 4–6px radii, platform-like controls, clear keyboard
focus, and a proportional reading font. Maintain high information density and
strong selected/unread states. Compose is a docked editor surface; Preferences
is a conventional sidebar-and-form surface. Modern remains an independent
existing layout and must not be visually altered.

Motion is functional and under 160ms: pane collapse, selection, and menu opening
only. Respect reduced motion.
